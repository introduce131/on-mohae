# 오늘 뭐할까?

## 기간
- 2025.8.19 ~ 2025.11.17

<br/>

## 프로젝트 소개
- 이 프로젝트는 사용자의 취향, 위치, 예산을 기반으로 최적의 데이트 코스를 자동 추천하는 웹 애플리케이션입니다.
- 카테고리 기반 추천, 사용자 선호도 반영, 지도 기반 탐색 기능을 통해
- **오늘 뭐하지?** 라는 고민 없이 손쉽게 다양한 데이트 루트를 만들 수 있도록 설계했습니다.
- 본 프로젝트는 실제 사용자 선호도 분석, 기능 정의, 화면 흐름 설계 등 사용성이 높은 데이트 코스 추천 서비스를 목표로 개발되었습니다.

<br/>

## 주요 기능
1. 데이트 코스 자동 추천
- 사용자의 관심사(카페, 맛집, 활동, 산책 등)를 기반으로 코스를 조합
- 예산/시간/위치 등 조건 필터링 가능
- 매번 다른 추천이 제공되도록 다양성 알고리즘 적용

2. 장소 상세 정보 제공
- 장소 사진, 리뷰 수, 별점, 영업시간 등 종합 정보 조회
- 해당 장소의 추천 이유 및 연관 카테고리 표시
- 지도 기반 위치 확인

3. 주변 기반 탐색 기능
- 현재 위치 기준 반경 내의 추천 스팟 탐색
- 카페 / 식사 / 활동 등 필터 제공

4. 즐겨찾기 & 최근 본 장소
- 사용자가 마음에 든 장소를 저장하여 나중에 다시 조회
- 최근 본 장소 자동 기록
- 한 번 본 정보를 다시 찾기 쉽게 UX 최적화

5. 사용자 맞춤 프로필 기능
- 선호 카테고리 기반 개인화 추천 강화
- 예산 정보와 데이트 성향 반영
- 사용 패턴에 따른 추천 품질 향상

6. 데이트 코스 저장 기능
- 추천받은 코스를 사용자가 저장할 수 있음
- 사용자만의 개인 코스 저장
